# 个人静态博客

## 技术框架

hexo + butterfly 主题 + 若干自定义插件脚本做优化调整

## 主要特点

- 将**原生Markdown笔记文件**（文件夹）转为博客网站。
  - 推荐内部使用标准语法的**相对路径链接**，脚步自动转换笔记之间的链接使之可以有效跳转（附件图片也可以正常显示）。
  - hexo原本不支持附件与文章一起存放，但为了方便拷贝、个人统一管理，添加了脚本做处理。
- 与 Obsidian 软件组合使用，其支持**多级标签**功能，在文件头部属性中通过标签就可指定笔记的标签（tags）与分类（categories）。

## 工作流

### 工作文件夹结构

- 私有Markdown笔记git仓库
  - Obsidian 软件配置与插件git仓库
  - Markdown笔记根目录（使用自动同步软件，备份整个文件夹）
    - ...（其他私有笔记）
    - 发布文件夹（公开文章与附件，按年份分组）
      - 2023
      - ...

### 定期发布文章

- 将发布文件夹内容完整同步到本项目。编写了`syncPostFolder.js`脚本，在node环境运行即可自动完成。
- 提交更改到master分支。
- （可选）使用post分支的public文件夹部署以大幅减少服务器部署时间。在post分支上合并master分支，本地运行`hexo g`在public文件夹生成静态文件，然后提交。

### 更新项目配置

统一在framework-config分支进行本项目的配置调整，包括添加脚本等，测试正常后合并到master分支。

脚本调试：在`debug.js`脚本封装了`hexo g`命令以便调试。
