## 初识

今天突然知道静态博客这个东西（尽管已经火星很多年了），从网络文章有了初步了解：

- https://zhuanlan.zhihu.com/p/74778630
- https://zhuanlan.zhihu.com/p/111832962

先是想利用 git 服务器免费发布，**因为现在国外 github 有风险，优先找 gitee 支持的、大众的框架，先随便选了一个框架 Hexo** 就安装起来了。（后来也没有尝试其他不支持的比如 VuePress）

```bash
npm install hexo
npx hexo init
```

**官方文档** 还不错: https://hexo.io/zh-cn/docs/

## 博客主题

顺理成章找主题来用，看了几个文章和主题但最终没有采用：

- https://blog.csdn.net/fail_perfectly/article/details/83791781
- https://theme-next.iissnan.com/getting-started.html

官网上的主题都很一般，最终好像是百度到了一个感觉不错的的 [butterfly](https://butterfly.js.org/)

一开始也正常使用 clone 方式安装（后来才改为 npm 安装）：

```bash
git clone https://github.com/SineObama/hexo-theme-butterfly.git themes/butterfly
npm install hexo-renderer-pug hexo-renderer-stylus
```

**阶段总结**：该框架有分类、标签功能，感觉容易整合已有内容，能够轻量使用（一开始还想和目前的 Obsidian 仓库融合，后来发现没必要）。

初步根据官方文档和主题的说明文档进行个人配置。

### 评论系统

评论系统需要引入外部服务，考虑以下几点：

- 互联网服务，在中国大陆稳定使用。（非私有部署）
- 暂不考虑github，感觉会与其他内容耦合。

#### 2023年3月19日

忘了为什么一开始选了 [Valine](https://valine.js.org/quickstart.html)，我建了个博客应用，在[LeanCloud](../../231_用户账号/互联网账号/LeanCloud.md)平台找到了 [数据存储中的评论管理](https://console.leancloud.cn/apps/tbY73w6X4UlApBPiJTgNS8r3-gzGzoHsz/storage/data/Comment)。过程可能也有参考文章设置： https://zhuanlan.zhihu.com/p/581640626

但没有绑定域名，不太懂这个，好像只是评论也还能用，官方文档也没有说要域名（诶嘿）。实际上后来发现首页的最新评论出不来，可能真的会有服务api不稳定。

#### 2023年4月8日

今天换成Waline试试，因为碰巧发现butterfly（留言板）默认就是用的它，和Valine一样需要使用[LeanCloud](../../231_用户账号/互联网账号/LeanCloud.md) ，看了[Waline快速上手](https://waline.js.org/guide/get-started/)也警告提醒说[LeanCloud](../../231_用户账号/互联网账号/LeanCloud.md)国内版需要完成备案接入。它虽然需要后端，但网上有平台可以免费部署。只不过推荐的[vercel](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fwalinejs%2Fwaline%2Ftree%2Fmain%2Fexample)似乎不能正常访问，会自动跳转到github，不懂原因。

找了另一个免费部署方法：[Deta 部署 | Waline](https://waline.js.org/guide/deploy/deta.html) ，部署平台[Deta Space](../../231_用户账号/互联网账号/Deta%20Space.md)，但是本地调用发现速度比较慢了。

### 额外配置

参照主题的说明文档，

- 搜索系统选用官方本地搜索插件 `hexo-generator-search`
- 字数统计选用官方插件 `hexo-wordcount`。

## 内链问题

实际用起来后碰到内链问题，文章之间的链接我使用的相对路径，链接的是完整文件名（拓展名.md），网站发布后不能正常跳转。

搜到了 hexo-generator-alias 但好像不是解决这个问题。

有一个想法是用代码调整生成内容，比如把 md 文件里的相对路径的 md 链接都替换为 html 后缀

感觉上最简单还是调整内置 response 头，如果有方法的话。（后来发现是理解错误，这样不能解决问题）

2023 年 3 月 14 日，内链问题暂时没有头绪，想尝试一下其他博客框架，参考了文章：

- https://www.yundashi168.com/254.html
- https://www.jianshu.com/p/10fcae6fada1

了解到 hugo 两年没发布版本更新了，就不想用，想先试试 [jekyll](https://github.com/jekyll/jekyll)。结果发现它对源笔记文件名有硬性要求：`YEAR-MONTH-DAY-title.MARKUP` 瞬间不想用了。

最后回归 Hexo，渐渐地发现还是有解决办法的，虽然可能不够优雅：[Hexo网站文章内链问题](Hexo网站文章内链转换问题.md)
