## 首次使用

从 [Obsidian插件安装全网最全攻略 - 知乎](https://zhuanlan.zhihu.com/p/497015024) 下载了魔法访问插件 [obsidian-proxy-github](https://gitee.com/juqkai/obsidian-proxy-github) 以及 [Obsidian新手免配置开箱即用库 2022-4-13.rar](https://wws.lanzoul.com/b0273yjmd?pwd=55qz)。

### 准备工作

#### 软件开箱与笔记迁移

先按照前文使用开箱的插件。

1. 更新了所有插件。
2. 解决一些会用到的快捷键冲突。
3. `.obsidian` 文件夹（里面带有软件配置和插件）复制到自己的笔记本文件夹试用。
4. 整理笔记结构，分离图片等附件与文本笔记。文本笔记存放在单个文件夹 *主笔记本* 中，调整附件默认存放路径的设置，设置在文件夹 *笔记附件* 中。
5. （个人需要）使用 git 保存内容。分别在仓库根目录、`.obsidian` 文件夹创建 git 仓库，分开提交软件配置与插件（体积较大）、笔记内容与附件（体积较小）。其中配置仓库里忽略了一些使用记录的数据。
6. （个人需要）使用坚果云同步文本笔记（即 *主笔记本*）。
7. （个人笔记整理）*主笔记本* 下的部分文件夹试用序号开头，一方面也是为了来排序。删除或迁移了以前的父目录对应的笔记。调整了无效的标签。将以前的文档块创建时间标签替换为元数据。

#### 快捷键配置

markdown 格式转换，能用的话优先用软件自带的，其次用插件功能，两者都 **没有默认快捷键设置** 的，尽量设置为网上找的通用快捷键。目前设置了以下几个：

- 无序列表：`Ctrl+Shift+]`（原生）
- 引用：`Ctrl+Shift+Q`（原生）
- 有序列表：`Ctrl+Shift+[`（原生）
- 代码块：`Ctrl+Shift+K`（插件：增强编辑）
- 调低标题级别：`Ctrl+-`（插件：增强编辑）
- 调高标题级别：`Ctrl+=`（插件：增强编辑）
- 转换 callout 语法：Alt+A（插件：增强编辑，暂时设置）
- Toggle Code（切换行内代码）：Alt+D（插件：cMenu，参考了增强编辑插件中已经被删除的快捷键）

其他快捷键调整：

- 打开设置：`Ctrl+M`（原生，暂时设置，因为默认的 `Ctrl+,` 不知道为什么在编辑时用不了）
- 切换编辑/预览视图：~~`Ctrl+E`~~（原生，不需要看预览模式就没用，窗口右上角按钮也可以切换）
- 切换实时阅览/源码模式：`Ctrl+E`（原生，代替上面的切换功能，有时候需要在纯源码下编辑，避免样式跳来跳去难以交互）
- `Go to tab #*`：~~`Ctrl+*`~~（原生，与标题级别快捷键冲突）
- Vault Search：`Ctrl+Q`（插件：Omnisearch，暂时设置）

#### 其他零碎配置

- 【软件设置】文件与链接 -->（关闭）使用 Wiki 链接。而是使用标准 markdown 链接语法，在其他 markdown 软件中 **兼容性** 更好（如 wolai）。
- 【软件设置】编辑器 -->高级 -->自动转换 html（开启）。

### 插件与配置与评价

#### icon-folder

估计是箱中的插件版本比较旧与 ob 不匹配，提示需要人为修正目录路径，从 `plugins/obsidian-icon-folder/icons` 修复为 `.obsidian/plugins/obsidian-icon-folder/icons`（一开始我并不理解此提示的意思，后来找到源码 v1.2.2 版本的发布说明才看懂）

![弹窗的提示内容](../../../笔记附件/Pasted%20image%2020221029090240.png)

#### Outliner

它限制了光标使其难以移动到列表符号位置，导致不便于调整列表缩进等操作，故关闭了此设置。

![设置项预览](../../../笔记附件/Pasted%20image%2020221028211226.png)

#### templater

第三方模板插件，使用后可关闭核心插件 `模板`。

编写了两个目标：通用笔记元数据模板、更新时间默认格式模板。

#### Calendar

核心插件 `日记` 功能似乎不太够用，但有 `Calendar` 插件提供拓展功能，设置 *两者* 的笔记存放位置为 `主笔记本/daily note/2022`。创建并设置日记模板 `主笔记本/笔记模板/日记模板`。

模板语法似乎与 `模板` 插件一致，另一种方法是用 `templater` 语法，然后在创建之后再执行其 Replace 功能。

#### 增强编辑（Enhanced-editing，配置包中的原名：ZH 增强编辑）

很多 markdown 语法转换的快捷键。而且是中文插件，功能大致已经包括了英文插件 `cMenu`。

可能有用的快捷键：

- 去除 markdown 语法。转换无语法：`Ctrl+Alt+Z`，复制无语法：`Ctrl+Alt+C`

插件源码：[obsidian-canzi/Enhanced-editing: 旨在增强Obsidian编辑功能的插件](https://github.com/obsidian-canzi/Enhanced-editing)。插件没有上架社区商店，安装了另一个插件 [obsidian42-brat](https://github.com/TfTHacker/obsidian42-brat) 经由它来安装。

#### dataview

开箱时是关闭的，我启用了。

#### Linter

开箱时是关闭的，开启后 2022 年 11 月 13 日发现它会引起粘贴 markdown 格式链接会引起程序崩溃无反应，暂时关闭使用。（`v1.7.0` 与 `v1.7.1` 版本都有问题）

2022-10-29 21:44 左右软件似乎崩溃了一次（在剪切粘贴一段文本的时候，具体不记得了），界面没有反应，但能正常关闭程序没有报告异常（同时打开的另一个工作区窗口是正常的，先一步关闭了）。可能也是此插件问题。

### 后续添加插件

#### consistent attachments and links

用了几个月（1.1.16 版本）才发现移动笔记文件时，被移动的笔记中的内部链接不会被更新。百度了 `obsidian移动文件时不会更新链接` 碰见视频 [Obsidian有救了？再也不怕笔记“移动”和"重命名"了_哔哩哔哩_bilibili](https://www.bilibili.com/video/av767773591) 用的也是私有链接，但还好在视频评论区看到了这个插件，它可以全面检查修复并接管链接，全部统一为标准格式的相对链接。（此外还有附件移动功能，但我不用）

#### OmniSearch

突然想起自带搜索好像优先顺序不太好（比如文档标题不优先显示），随手找了一个搜索插件 OmniSearch，先试试看。（不过自动安装出了问题，没有下载 js 文件，手动下载了 1.7.8 版本）

#### Excel to Markdown Table

粘贴 xls/xlsx 表格数据时支持转换。

#### Paste URL into selection

便捷地粘贴链接创建超链接。可能也就少一两次按键。

### 未解决的问题

- `obsidian-proxy-github` 插件开启后，使用软件时经常会刷出代理日志，阻挡了鼠标点击右上角的部分功能。日常使用只能先关闭它。
- `tab` 键会输入制表符，不符合平常代码习惯，但在编辑器设置中设置为输入空格仍然无效，只能暂时妥协用制表符了。
- 外部导入的 markdown 笔记带有附件，希望把附件统一移动集中到一个文件夹中，但没有找到好方法。
