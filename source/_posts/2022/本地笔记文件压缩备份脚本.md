## 思源 siyuan 数据备份批处理脚本

```bat
echo "backup siyuan notebook data directory. only backup current directory."
set bakname=%Date:~0,4%-%Date:~5,2%-%Date:~8,2%-siyuan-main-data.zip
set output=D:\Downloads
set zipcmd=D:\Program Files\7-Zip\7z.exe

set current=%cd%
set outputfile=%output%\%bakname%
rem exclude internal directory ".siyuan"
"%zipcmd%" a -tzip "%outputfile%" "%current%" -xr"!*/.siyuan/"
explorer /select,"%outputfile%"

```
